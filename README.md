# Hunter Assassin - Complete Stealth Action Game

## Run
1. Install Python 3.10+.
2. Install Pygame:
   `python -m pip install pygame`
3. Run:
   `python main.py`

## Controls
- WASD / Arrow keys: Move
- Shift: Sprint
- C: Crouch / stealth
- F or Left Mouse: Attack
- Space: Dash
- ESC: Pause
- R: Restart
- M: Main menu

## Included
- Manual attack system with range, direction and cooldown
- Enemy health and different enemy types
- Patrol / Suspicious / Chase / Search AI
- Vision + hearing
- Last known player position
- Player health, armor, stamina, sprint, crouch and dash
- Detection meter
- 10 mission campaign
- Objectives, collectibles, timer and star rating
- Commander/Boss/Target enemy types
- Coins, XP and upgrades
- Persistent save.json
- Editable levels/levels.json
- Menus, settings, pause, replay and progression
- Particle effects and screen-ready architecture

The generated version intentionally uses procedural/vector graphics so it runs without requiring external image assets. Replace/add files under assets/ when you want sprite art, animation frames and professional sound.
